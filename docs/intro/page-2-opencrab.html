02 / cloud context

OpenCrab은 클라우드 경계다

CrabAgent가 온톨로지를 불러올 때, OpenCrab은 연결·권한·팩 카탈로그를 구분해서 다뤄야 하는 외부 경계로 표현됩니다.

팩

실제 검색 결과에서 Fable5xGLM5.2가 확인됐고, 태그에는 crab-agent와 mcp가 있습니다.

권한

검색 응답은 admin_all_customers 범위를 표시합니다. 소유자 전용 근거로 확대하지 않습니다.

경계

캐시 변화가 0이면 최신 SaaS 전체 동기화는 수행하지 않습니다.

확인된 근거: OpenCrab 팩 검색 응답의 Fable5xGLM5.2 결과와 현재 미션의 빈 인벤토리 delta.
추가 확인 필요: OpenCrab SaaS의 공식 제품 설명, 요금·서비스 범위·실제 팩 내용은 이 자료에서 단정하지 않습니다.
