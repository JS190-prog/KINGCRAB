03 / local memory

LocalCrab은 관찰 가능한 로컬 기억이다

소개 자료에서 LocalCrab은 전체 클라우드 카탈로그를 복사하는 이름이 아니라, 로컬 캐시와 명시적 동기화 상태를 보여주는 층으로 설명합니다.

읽기

/ontology는 로컬 OpenCrab 인벤토리 캐시를 읽습니다.

동기화

/ontology sync는 명시적으로 요청할 때만 전체 read-only sync를 수행합니다.

차이

/ontology diff는 추가·삭제·변경만 보여줍니다.

확인된 근거: CrabAgent-CLI README의 `/ontology`, `/ontology sync`, `/ontology diff` 설명과 CLI의 ontology 명령 구현.
추가 확인 필요: LocalCrab의 공식 독립 제품 정의와 내부 저장소 세부사항은 별도 공식 소스가 필요합니다.
