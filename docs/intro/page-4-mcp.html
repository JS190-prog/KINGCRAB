04 / mcp tool contract

CrabAgent MCP는 계획과 상태를 연결한다

opencrab_crab_agent는 로컬 빌드 입력을 모으고, 계획을 만들고, 업로드 세션 상태를 확인하는 Expert 도구 계약으로 노출됩니다.

plan

팩 이름·로컬 데이터 폴더·온톨로지 목적을 받아 빌드 계획을 구성합니다.

create_upload_session

계획된 결과를 위한 일회성 업로드 세션을 생성하는 계약입니다.

status

upload_session_id로 업로드 세션 상태를 조회합니다.

확인된 근거: 현재 노출된 MCP 도구 스키마. 이는 “도구가 노출됨”의 증거이며, 실제 호출 성공이나 업로드 완료의 증거는 아닙니다.
추가 확인 필요: 실제 실행 결과·업로드·SaaS 인제스트는 이번 미션에서 수행하지 않았습니다.
