05 / local-first runtime

crab은 미션을 오래 붙잡는다

CrabAgent CLI는 로컬 우선·온톨로지 지향 코딩 에이전트입니다. 공개 명령은 crab이고, 내부 durable runtime이 미션 상태를 보존합니다.

시작

crab은 명령 덱을 열고, crab run "목표"는 미션을 제출합니다.

상태

미션 상태는 .crabagent/state.sqlite3에, 산출물은 mission별 artifacts에 둡니다.

관찰

status, inspect --latest, replay --latest로 결과를 확인합니다.

확인된 근거: CrabAgent-CLI README와 CLI 구현.
추가 확인 필요: 실제 실행 화면·성공 미션·배포 상태는 이 정적 자료가 증명하지 않습니다.
